Carwash
Sistema de reservas para un carwash( lavado de carro ). 

## 🌐 Proyecto hospedado
URL del proyecto: https://alexiscl0.github.io/ProyectY/

## 📄 Descripción
Este proyecto consiste en una aplicación web para la gestión de reservas de un carwash,
permitiendo a los usuarios registrar sus datos, seleccionar un servicio y enviar la
información mediante una interfaz web sencilla e intuitiva.

## 🛠️ Lenguajes utilizados
- HTML
- CSS
- JavaScript
- Python (Flask)
- SQL (MySQL)
